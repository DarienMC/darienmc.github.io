Our submission for the Alberta Game Jam 2024 given theme "Out of Order".

Game Jam Details

The Alberta Game Jam is an annual event where game developers of all skill levels from Alberta join together to create video games within 48 hours. There was a venue for the three major cities of Alberta: Edmonton, Calgary, and Lethbridge.

I participated in the Alberta Game Jam 2024 at the Lehtbridge venue in a team of 6 as a C# programmer in Unity. This year’s theme was Out of Order.

Once the theme was revealed, we decided as a team to make a 3D local multiplayer game about robots battling each other. I was mainly responsible for the game’s UI as well as the core events that are responsible for switching between views with the Model-View-Controller pattern in mind.
